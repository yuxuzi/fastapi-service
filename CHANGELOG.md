# Changelog

## 1.1.0

- The manifest declares `categories` and `keywords` for pytemplate-hub's filters and search
  (needs pytemplate-uv 3.4 or later).
- The README creates projects with the hub's short `-h yuxuzi/fastapi-service@v1.1.0` command.

## 1.0.0

- Initial release with two profiles: `service` (in-memory example resource) and `service-sql`
  (SQLAlchemy 2, SQLite by default).
